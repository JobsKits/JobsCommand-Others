在 [**MacOS**](https://www.apple.com/macos/) 上双击桌面的 `连接时间胶囊.command`，先看终端自述，再直接按回车，交由访达打开 `smb://AirPort.local/Data`。存在本人既有迁移配置时，还会验证共享身份、维护稳定的 Data 入口并装载缓存工作卷。

## 一、<span id="usage">使用方式</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

- 先确保电脑和时间胶囊处于可互通的局域网，设备已通电。
- 双击桌面快捷入口，或本目录的[真实脚本](./【MacOS】连接时间胶囊.command)。桌面入口是相对符号链接，需与同名包装目录一起保留。
- 自述后的提示出现时，直接按回车开始连接。输入任意内容后回车，或按 `Ctrl+C`，可以取消。脚本在确认后才创建日志和执行连接。
- 若出现系统登录框，在系统窗口完成本人认证，也可在该窗口取消。脚本不读取或保存密码，不访问钥匙串、不设置自动登录，README 和日志不记录密码。
- 已连接时可以再次双击。存在迁移配置时须等待终端明确显示“工作卷已就绪”，再启动VM或使用迁出的缓存；单纯出现Data文件夹或连接请求提交成功不代表缓存工作卷就绪。
- 重启 Mac 后，双击桌面快捷入口并按回车重新挂载。`JobsCache` 是长期保留的缓存工作卷，实体为时间胶囊上的 `JobsMacStorage/JobsCache.asif`；不要删除此文件，程序使用期间也不要推出工作卷。
- 使用结束后先停止VM及正在使用迁出缓存的程序，再在访达推出 `JobsCache`（实际挂载点名为 `CacheVolume`），最后推出Data共享；待全部推出后再断开网络或关闭设备。脚本不提供强制推出或跳过锁定的操作。

## 二、<span id="behavior">连接行为与日志</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

- 无 `~/Library/Application Support/JobsTimeCapsule/migration.json` 时，由访达处理连接和认证，终端最多等待 120 秒获取目标共享的实际挂载和 SMB 统计。统计查不到时显示警告，访达仍处理原连接请求；不创建或修改 Data／CacheVolume 入口。
- “连接请求已交给访达”仅表示系统已接收请求；认证和原生失败提示由系统处理。配置模式继续执行下述身份验证，不能用 `open` 的退出码0替代挂载验收。
- 配置已启用时先短时检查已有共享；发现身份正确的唯一挂载便直接复用，不再次发送SMB URL连接请求。只有尚无匹配挂载时才请求系统连接并有界等待，以减少重复挂载与认证窗口；身份冲突或查询失败会保留现状并返回非零。
- 确认目标共享已挂载后，终端和日志显示 `AirPort.local` 解析出的局域网 IPv4，以及 `smbutil statshares -m <实际挂载点>` 的完整统计。存在迁移配置时，先验明工作卷身份并打开共享文件夹，再打印统计。以 `SMB_VERSION` 为本次连接协商的版本。诊断查不到时显示警告。
- 设备离线、网络不通、认证失败或标记缺失时会等待或明确报错；查找共享最长120秒，终端显示等待状态，可按 `Ctrl+C` 取消。恢复网络后可再次双击；取消时不承诺系统已撤回先前提交的连接或挂载请求，应按系统实际状态确认。
- 回车确认后，在系统临时目录新建独立私有日志，文件名以 `【MacOS】连接时间胶囊.` 开头，完整位置显示在终端中。日志记录连接阶段、验证结果、失败原因及真实退出码，不记录身份标记内容或凭据；临时文件可能被系统清理。终端中的 URL 使用绿色下划线，局域网 IPv4 地址值显示为绿色。`NO_COLOR` 或非交互输出保持纯文本，落盘日志始终无颜色控制码。

### 2.1、<span id="managed-work-volumes">既有配置下的工作盘连接</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

- 配置必须是本人拥有的普通文件。脚本只读取现有 `storage_token`、`cache_volume_uuid` 及可选的 `cache_image_name` 字符串字段，不生成配置、不编造UUID，也不把标记写入日志。镜像名白名单仅允许 `JobsCache.dmg` 或 `JobsCache.asif`，省略时默认 `JobsCache.dmg`，其它文件名及路径穿越均拒绝。
- 先将受管路径 `~/Library/Application Support/JobsTimeCapsule/DataMount` 纳入候选，再检查 `/Volumes/` 下的候选；每项均须同时出现在真实SMB挂载表中且共享内 `JobsMacStorage/.jobs-storage-token` 与配置一致。同名本地Data目录或空DataMount目录不会被当成共享；没有匹配项会有界等待，存在多个匹配项则保留现状并停止。此发现逻辑不修改挂载策略或保存认证信息。
- `~/Library/Application Support/JobsTimeCapsule/Data` 是受管符号链接。验证唯一共享后原子更新到实际挂载位置，可适配Data被系统改挂为 `Data-1` 的情况；同名真实文件或目录保留并报错。
- 缓存使用实时APFS工作卷，供迁出后沿原路径直接使用，不是归档。`JobsCache` 是迁移时新建的ASIF工作卷，当前逻辑容量32 GiB，物理占用随内容增长，后续可按需另行扩容；既有镜像位于共享内 `JobsMacStorage/<cache_image_name>`，由完成准备后的配置指定 `JobsCache.asif`。省略镜像名时仍兼容默认DMG，实际卷容量以配置方案和卷信息为准。脚本不自行创建镜像，也不把创建或复制完成当成挂载成功；挂载点固定为支持目录下的 `CacheVolume`，须经过实际身份与使用验收。VM仍位于共享中的原目录，不放入缓存镜像。
- `CacheVolume` 已挂载时，通过 `diskutil info -plist` 与 `plutil`核对实际挂载点及卷UUID；尚未挂载时，确认既有镜像存在，再用系统 `diskutil image attach --mountPoint ... --mountOptions owners,nosuid,nodev ...` 装载。装载命令等待上限为120秒；超时后复核实际挂载点，已挂载且身份核验通过才继续，否则返回124并提示稍后再次运行。系统请求可能在命令结束后继续处理，超时不等于已经撤回挂载；其它装载失败保留原生错误日志和退出码。
- 系统默认会为磁盘镜像附加隔离标志 `quarantine`，首次运行卷内程序可能需要在解锁后的Mac上完成安全确认。连接成功与数据校验通过不能代替程序启动验证；脚本保持系统安全策略。
- 未挂载的 `CacheVolume` 仅含 `.autodiskmounted` 时，先核对目录与支持目录在同一设备、目录及标记属于当前用户、标记是非符号链接的普通零字节文件。随后复核挂载状态、目录身份和全部内容，将该标记留存到支持目录内独立私有的 `CacheMountBackup.XXXXXXXX/`，再用 `rmdir` 移除空目录，由系统重新建立挂载点；留存位置同步显示并写入日志。留存文件不会自动删除；装载失败时仍保留，恢复网络或处理系统错误后可再次双击。
- 含其它文件（包括隐藏文件）的本地目录、非空或类型异常的挂载标记、其它UUID的已挂载卷、身份不符或锁定状态均保留并报错，不覆盖、不强制推出。检查期间出现新内容或新挂载时停止，不迁移或删除新增数据。最终还须核对卷内 `.jobs-cache-token` 与同一个 `storage_token` 匹配，全部通过后才显示“工作卷已就绪”并重新打开共享文件夹。
- 此入口仅连接和装载既有工作盘，不复制或删除迁移数据、不切换原路径、不调整代理或其它全局设置。迁出的目录通过原路径直接使用前，仍需完成各自的程序使用验收。

## 三、<span id="validation">验证范围</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

- 当前共享盘已通过原生认证、挂载、文件写入回读校验、小文件读写和改名验证，测试文件已清理。
- 2026-11-15 实测连接使用 SMB1。2026-11-21 通过桌面入口复用 `/Volumes/Data`，日志中局域网 IPv4 为 `192.168.1.3`、`SMB_VERSION` 为 `SMB_3.1.1`，工作卷身份核验通过。后续每次运行以当次日志为准。保留在可信局域网内使用，不向公网开放文件共享。实际传输速度取决于当前网络、设备负载和磁盘状态。
- 此快捷入口负责连接，并在有配置时核对和装载既有缓存工作卷；日常使用不会自动执行测速、文件读写验证或数据迁移。语法检查及受控隔离下的无配置请求成功／失败／超时、运行目录保留、退出清理、受管DataMount身份匹配和假本地目录拒绝验证通过。真实共享复用、正常卸载后由本入口重新装载已有数据工作卷也已通过；实际断网恢复尚未验证。
- 当前脚本语法检查及25项隔离回归通过，覆盖残留标记留存、真实／隐藏数据保护、异常文件类型、并发变化、装载失败与超时后的身份复核。本机于2026-11-18核实：本地挂载目录仅残留零字节 `.autodiskmounted`；标记已留存，`JobsCache.asif` 已重新挂载，后续入口复用共享并完成挂载点、卷UUID及卷内身份标记核验，退出码0。此结果仅确认连接与身份，不代替迁出程序运行或断网恢复验收。
