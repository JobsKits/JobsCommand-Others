## 🔥 <span id="前言">前言</span>

本目录提供[**macOS**](https://www.apple.com/macos/)脚本包、配套文档、资源及分类链接。

## <span id="jobs-toc-heading-2" data-jobs-toc="v2">一、目录用途 <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a></span><!-- jobs-toc:heading-end -->

本目录按工具包组织功能，每个主实现配有就近说明，分类相对链接复用同一主实现。各包内入口与README保持同层，使用[**macOS**](https://www.apple.com/macos/)的[**Zsh**](https://www.zsh.org/)、[**Homebrew**](https://brew.sh/)与Apple工具链；[根README](../README.md)保留逐入口用途和流程。

## <span id="jobs-toc-heading-3" data-jobs-toc="v2">二、运行与边界 <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a></span><!-- jobs-toc:heading-end -->

双击各包内 `.command`，`.sh`可在包内使用 `zsh ./脚本名.sh`。运行前阅读同目录README；原有数据备份、确认、日志与权限规则继续适用。分类链接仍指向同一MacOS树内主实现。Windows用户使用[WindowsOS说明](../WindowsOS/README.md)，Apple模拟器、Xcode及macOS系统权限工具只在此目录。
