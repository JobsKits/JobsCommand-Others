# `JobsMockData` 

> 将本地电脑作为服务器，模拟真实网络请求，请求后的数据可以自定义。启动后终端窗口可关闭（后台运作）

![Jobs倾情奉献](https://picsum.photos/1500/400 "Jobs出品，必属精品")

* 授权并运行`【MacOS】Mock.command` 

  * 实际上是执行`python3 -m http.server 8080`

  * ```shell
    ./【MacOS】Mock_后台版.command start
    ./【MacOS】Mock_后台版.command status
    ./【MacOS】Mock_后台版.command stop
    ./【MacOS】Mock_后台版.command restart
    ```

* 涉及到的第三方插件

  * [**brew**](https://brew.sh/)、[**python3**](https://www.python.org/)、[**fzf**](https://github.com/junegunn/fzf)
